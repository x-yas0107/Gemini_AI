# 🎹 UIAPduino Piano Roll Synthesizer

ブラウザ上のピアノロール（Web Serial API）から、UIAPduino（CH32V003搭載ボード）をコントロールして鳴らす、**本格6和音シンセサイザー**です！
単純なブザー音ではなく、マイコン内で「波形合成（ノコギリ波・三角波など）」と「エンベロープ（音の減衰カーブ）」をリアルタイム演算し、ゲーム音楽やシンセサイザーのようなリッチな音色を奏でます。

## ✨ 主な機能
*   **ブラウザ完結UI**: ソフトのインストール不要！ChromeやEdgeでHTMLファイルを開くだけで動きます。
*   **MIDIファイル読込**: お手持ちのMIDIファイル（.mid）を読み込み、自動で6チャンネルに割り当てて再生します。
*   **専用の9プリセット**: ピアノ、ストリングス、ベースなど、楽器の特性に合わせた「波形×エンベロープ」を自動設定。
*   **通信の完全最適化**: 独自の通信フォーマットにより、シリアル通信の渋滞や音飛び（UARTオーバーラン）を完全に排除しました。

## 📍 UIAPduino I/O ピンマップ (完全版)

本プロジェクトにおける、UIAPduinoのピン割り当ておよび電源・書き込み系のピン一覧です。

| UIAPduino | ポート | 役割 | 備考 |
| :--- | :--- | :--- | :--- |
| **5V** | - | **5V電源出力** | USBからの5V |
| **3V3** | - | **3.3V電源出力** | 3.3Vロジック電源 |
| **GND** | `GND` | **グラウンド** | 電源・信号の基準（複数あり） |
| **11** | `PD1` | **SWDIO** | プログラム書き込み・デバッグ用 (WCH-LinkE等と接続) |
| **RST** | `PD7` | **RESET** | マイコンのリセット |
| **15** | `PD5` | **シリアル送信 (TX)** | PCとの通信用（ブラウザへの返信等） |
| **16** | `PD6` | **シリアル受信 (RX)** | PCからのコマンド受信 |
| **12** | `PD2` | **音声出力 1 (PWM)** | スピーカーの `+` へ接続 (TIM1_CH1) |
| **6** | `PC4` | **音声出力 2 (PWM)** | スピーカーの `+` へ接続 (TIM1_CH4) |
| **2** | `PC0` | **CH1 発音LED** | ボード上の内蔵LEDと連動して光ります |
| **5** | `PC3` | **CH2 発音LED** | 外部LED用 |
| **7** | `PC5` | **CH3 発音LED** | 外部LED用 |
| **8** | `PC6` | **CH4 発音LED** | 外部LED用 |
| **9** | `PC7` | **CH5 発音LED** | 外部LED用 |
| **10** | `PD0` | **CH6 発音LED** | 外部LED用 |

> **💡 高音質化のヒント:** 音声出力ピン（12番または6番）からスピーカーへ直接繋ぐことも可能ですが、抵抗とコンデンサを使った簡単な「ローパスフィルタ（RCフィルタ）」を挟むことで、PWM特有のノイズが消えて非常にクリアで美しい音になります。

## 🚀 使い方
1. **マイコンの準備**
   WCH-LinkE等を11番(PD1/SWDIO)・3V3・GNDに接続し、本リポジトリのC言語スケッチ（`main.c`）をコンパイルしてUIAPduinoへ書き込みます。
2. **ブラウザでUIを開く**
   UIAPduinoをPCにUSB接続した状態で、`MIDI_S.html` をChromeやEdgeなどのWeb Serial API対応ブラウザで開きます。
3. **接続する**
   画面左上の「接続」ボタンを押し、ポート一覧からUIAPduinoのシリアルポートを選択します。
4. **音楽を鳴らす！**
   *   「MIDI:」から手持ちのファイルを選ぶと、自動で解析して楽譜が並びます。
   *   画面下の鍵盤をクリックするか、グリッドをクリックして直接音符を打ち込むこともできます。
   *   ミキサーパネルのプルダウンから、楽器の種類（ピアノ系、ストリングス系など）を自由に変更して音色の違いを楽しんでください！
