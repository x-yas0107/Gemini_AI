# CH32V003 高精度周波数カウンター
### DIY Frequency Counter Project — Firmware V0.23

**CH32V003を使用した小型・高性能DIY周波数カウンター**

低コストのマイコンと入手しやすい電子部品を使用し、安定した周波数測定を目指して開発したDIY測定器です。

ハードウェアタイマーによるパルスカウント、アナログ入力段、独自の校正機能を組み合わせています。

当初は初心者向けのDIY測定器として開発を開始しましたが、試作と改良を重ね、当初の想定を超える性能を実現しました。

## 2. ハードウェア構成

CH32V003のハードウェアタイマーを利用し、CPUによるソフトウェアカウントへの依存を抑えた測定方式を採用しています。

### MCUの主な機能

- TIM2：ETR入力による外部パルスカウント
- TIM1：測定ゲート用の周期割り込み
- OLED：測定周波数の表示
- GPIO：操作スイッチ、スピーカー出力、リセット
- 内蔵Flash：校正データの保存

### 測定方式

外部入力信号をTIM2のETR端子に入力し、ハードウェアカウンターでパルスを計数します。

TIM1は0.5ms周期で割り込みを発生させます。

割り込みごとにTIM2のカウント値を読み取り、前回との差分を累積します。

これを2,000回繰り返すことで、1秒間の測定ゲートを構成します。

**0.5ms × 2,000 = 1秒**

したがって、累積されたパルス数が基本的にHz単位の測定値となります。

### 自動プリスケーラ切り替え

入力周波数に応じて外部入力のプリスケーラを自動的に切り替えます。

- 約14MHz以下：直接カウントモード
- 約16MHz以上：1/4分周モード
- 切り替え付近ではヒステリシス制御を使用

これにより、境界付近での不要なモード切り替えを抑制します。

## 3. アナログ入力段

本機の性能を支える重要な部分がアナログ入力回路です。

初期試作では、手持ち部品を使用したユニバーサル基板による製作を行いました。

### 入力段の主な構成部品

- 2SK128：FET入力段
- 2SC1815：信号増幅段
- フェライトビーズ：高周波ノイズ抑制
- カップリングコンデンサー：信号経路の分離
- アンプ部電源の分離：デジタル回路からのノイズ回り込み対策

FET入力段による高入力インピーダンス化と、後段アンプによる信号増幅を組み合わせています。

また、電源ラインや信号経路の分離によって、デジタル回路からのノイズの影響を低減する構成としています。

これらの組み合わせが、測定の安定性に寄与していると考えられます。

### Hフィールドプローブによる測定

Hフィールドプローブを使用した非接触測定にも対応しています。

電子回路のスイッチング動作に伴う磁界を検出し、周波数を測定することができます。

※現状の試作機はユニバーサル基板で製作しており、ベタアースは使用していません。正式な回路図は未作成です。

## 4. 校正機能

測定ゲートを生成する基準クロックの誤差を補正するため、独自の校正機能を搭載しています。

### 校正機能の特徴

- 校正用トーンの周波数を約0.25Hz単位で調整
- 基準トーン：1kHz
- UP / DOWNスイッチによる調整
- 校正状態の表示
- 校正値を内蔵Flashへ保存

校正値は内蔵Flashの最終64バイト領域に保存されます。

`0x08003FC0`

電源を切っても校正値は保持されます。

### オシロスコープがない場合の校正

本機はDIYユーザーでも校正できるように設計しています。

オシロスコープがない場合でも、音声帯域のビートを利用した校正方法を用意しています。

これにより、高価な測定器を持たないユーザーでも校正に挑戦できます。

より精密な校正には、オシロスコープや適切な周波数基準器を使用できます。

## 8. 実機での測定結果

### 直接入力による周波数測定

約5kHz～30MHzの範囲で安定した測定動作を確認しています。

### TinySAとの比較

30MHzの測定時、TinySAの表示は次のとおりでした。

`30.000 MHz`

本機の表示：

`30.00000 MHz`

両者の表示が一致することを確認しました。

これは試作機の評価において非常に興味深い結果でした。

ただし、表示値の一致は絶対精度を保証するものではありません。

### Hフィールドプローブによる測定

Hフィールドプローブを使用し、電子回路のスイッチング信号を非接触で検出する試験も行っています。

これにより、微小な信号を磁界結合によって取得し、周波数測定できることを確認しました。
