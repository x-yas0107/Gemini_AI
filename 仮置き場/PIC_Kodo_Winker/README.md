# P84_Kodo_Winker
## PIC16F84A 滑らかLEDウインカーコントローラー

### 〜 8ビットマイコンで実現する、自然な光のフェード制御 〜

**P84_Kodo_Winker** は、PIC16F84Aを使用したLEDウインカーコントローラーの製作プロジェクトです。

ウインカーの点滅に合わせてLEDの明るさを滑らかに変化させ、一般的なON/OFF点滅とは異なる、自然な光の動きを実現します。

専用PWMハードウェアを持たないPIC16F84Aで、ソフトウェアによる64段階PWMと二次曲線フェード制御に挑戦しています。

古典的な8ビットマイコンの限られた性能を活かし、シンプルな回路と工夫したプログラムで動かすことを目指しています。

---

## 1. 主な機能

- **64段階ソフトウェアPWM**
  - LEDの明るさを64段階で制御。
  - 滑らかな明るさの変化を実現。

- **二次曲線フェード制御**
  - 徐々に明るくなり、自然に暗くなる光の演出。
  - 上昇・下降それぞれの時間を調整可能。

- **ウインカー連動**
  - 外部ウインカー信号に連動して動作。
  - 信号ONで運転開始、OFFで停止。
  - 電源投入時に信号がONなら、そのまま運転開始。

- **10段階の設定**
  - 点滅周期：10段階
  - フェード傾き：10段階

- **EEPROM設定保存**
  - 内蔵EEPROMに設定を保存。
  - 電源を切っても設定を保持。

- **LEDによる状態表示**
  - LEDの点滅回数で設定モードや保存完了を通知。
  - 専用ディスプレイを必要としないシンプルな操作系。

## 4. 入力信号の動作

基本的に、スイッチ入力はGNDへ接続するとONになる構成です。

| 入力 | HIGH（開放） | LOW（GND接続） |
|---|---|---|
| RB0 SELECT | OFF | ON |
| RB1 PLUS | OFF | ON |
| RB2 MINUS | OFF | ON |
| RB3 WINKER_IN | 待機・停止 | 運転 |

RB3には内部プルアップを使用します。

ウインカー信号がLOWになるとLED制御を開始し、HIGHになると停止します。

電源投入時にもRB3の状態を確認するため、ウインカー信号がすでにONになっている場合でも運転を開始できます。

---

## 5. 設定操作とLEDフィードバック

設定操作は3つのスイッチで行います。

| スイッチ | 操作 |
|---|---|
| SELECT | 設定項目の切り替え |
| PLUS | 設定値を増加 |
| MINUS | 設定値を減少 |

SELECTの短押しで設定項目を切り替え、長押し（約3秒）で設定を保存します。

### LED点滅による状態通知

LEDの点滅回数によって、現在の設定状態や保存完了を知らせます。

<box>
| 点滅回数 | 通知内容 |
|:---:|---|
| **1回** | 点滅周期の設定モード |
| **2回** | フェード傾きの設定モード |
| **3回** | EEPROMへの設定保存完了 |
</box>

専用ディスプレイを使わず、LEDそのものを状態表示器として利用する設計です。

## 6. 製作に必要なもの

- PIC16F84A
- +5V電源
- RC発振用部品
- LED
- LED電流制限抵抗
- LED駆動用トランジスタ等
- 操作用スイッチ
- ウインカー信号入力用インターフェース部品
- ICSP書き込み環境

※ LEDの種類や負荷に応じて駆動回路を設計してください。

※ 車両の12V信号をPICの入力端子へ直接接続してはいけません。ウインカー信号には、5V入力に適合する保護・レベル変換回路が必要です。

※ 車載用途では電源変動、逆接続、サージ、ノイズへの対策も必要です。現段階では実車への直接接続を保証するものではありません。

## 8. このプロジェクトについて

高性能なマイコンや専用PWM回路を使えば、同じような機能を実現することは難しくありません。

しかし、限られたメモリと少ない命令で、どこまで滑らかな制御ができるのか。

そこにPIC16F84Aを使う面白さがあります。

古いマイコンにも、まだまだ遊べる余地はあります。

**小さな8ビットCPUから生まれる、大きな可能性。**

P84_Kodo_Winker は、そんな電子工作の楽しさを形にするプロジェクトです。
