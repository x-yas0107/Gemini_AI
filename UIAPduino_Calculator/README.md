
# UIAPduino Calculator on GemOS

> **16KBの限界に挑む。CH32V003で駆動する本格派ジョイスティック電卓！**

## 📖 概要 (Overview)

わずか16KBのフラッシュメモリと2KBのRAMしか持たない極小マイコン「CH32V003」の中に、OS風のGUI環境「GemOS」と本格的な電卓アプリケーションを詰め込んだ限界突破プロジェクトです。

外部ROMに一切頼らず、独自フォント、スクロール可能な履歴機能、リアルタイム進数変換、そして独自アルゴリズムによる小数点計算など、電卓としての実用性を極限まで詰め込みました。（フラッシュメモリ使用率96%！）

## ✨ 特徴 (Features)

* 🕹️ **ジョイスティック・ドリブンUI**
アナログジョイスティック（X/Y軸＋押し込み）による直感的なマウスカーソル操作。
* 📜 **スクロール対応の計算履歴**
最大30行の履歴を保存。画面右側の履歴エリア上下端にカーソルを合わせることで、スムーズなスクロールによる過去の振り返りが可能。
* 🔢 **エンジニア向けリアルタイム進数変換**
現在の計算結果や、フォーカスしている履歴の数値を、画面上部で「DEC（10進数） / HEX（16進数） / BIN（2進数）」にリアルタイム変換。
* 🧮 **超軽量・固定小数点エンジン**
メモリを食いつぶす64bit演算（`int64_t`）や浮動小数点ライブラリを完全排除。数値を「100倍した32bit整数」として扱い、整数部と小数部を分割して筆算のように処理する独自アルゴリズムにより、16KBの壁を越えずに小数点以下2桁の計算を実現。
* 🎨 **スマートな動的UIレイアウト**
「BS」や「＝」キーを横2マス分に拡張し、文字のセンタリングと当たり判定を動的に計算する美しいグリッドUI。

## 🛠 ハードウェア構成 (Hardware)

* **MCU**: CH32V003 (16KB Flash / 2KB RAM)
* **Display**: 128x64 OLED (I2C接続 / ソフトウェアI2C制御)
* **Input**: 2軸アナログジョイスティック ＋ タクトスイッチ
* **Development**: Arduino IDE (UIAPduino Core)

## 💡 技術的なハイライト (Technical Highlights)

開発における最大の敵は「16KBの壁」でした。
小数点演算を実装した瞬間にコンパイラが裏で重い演算ライブラリを呼び出し、フラッシュメモリがパンク。そこから、定数配列の `static const` 化によるROMへの押し込み、重複する演算処理の関数統合、そして何より「32bit整数の枠内で完結する独自の固定小数点演算ロジック」をゼロから構築することで、約600バイトのシェイプアップに成功。見事15.7KB（96%）にピタリと収めました。

## 🎮 操作方法 (How to Use)

1. **カーソル移動**: ジョイスティックを上下左右に倒す
2. **クリック（決定）**: ジョイスティックを押し込む
3. **履歴の確認**: 画面右半分のエリアで、上端・下端にカーソルを当ててスクロール
4. **進数変換の切り替え**: 画面左上の「DEC / HEX / BIN」エリアをクリック
