# 🕹️ UIAPduino SN76489 MIDI Synthesizer

[![Version](https://img.shields.io/badge/Version-V0.20(Sketch)_/_V0.10(HTML)-blue.svg)](https://github.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

Webブラウザからレトロ音源チップ「SN76489（DCSG）」を自在に操る、次世代のピアノロール＆MIDIシーケンサーシステムです。

専用ソフトのインストールは一切不要。HTMLファイルをブラウザで開くだけで、Web Serial APIを通じてマイコン（Arduino）と直接通信し、リアルタイムな音作りとMIDI演奏を実現します。

## ✨ 主な特徴 (Features)

### 🎹 1. ブラウザ完結の本格ピアノロール・エディタ
直感的なマウス操作で音符の入力・編集（長さの伸縮）が可能。プロジェクトの保存・読み込みにも対応し、いつでもどこでもチップチューン作曲が楽しめます。

### 🧠 2. 「メロディ保護」＆ 賢いMIDIインポート
一般的なMIDIファイルを読み込む際、トラックのノート数を自動解析。
一番音符の多いトラックを「🌟主旋律候補」として提示し、ノイズ専用チャンネル（CH4）にメロディが誤って割り当てられ、曲が壊れるのを自動で防ぎます。

### 🥁 3. 自動ドラムキット・エンジン搭載（Auto Drum-kit）
SN76489の最大の弱点である「CH4（ノイズチャンネル）は1種類の音しか出せない」という仕様をソフトウェアで克服。
MIDIのドラムノート番号（Kick, Snare, Hi-hat等）を受信した瞬間、**マイコン側でノイズの種類（ホワイト/周期）と減衰（Decay）をリアルタイムに自動切替**します。単なる雑音が、本格的な「8-Bitドラムセット」に生まれ変わります。

### 🎛️ 4. リアルタイム・エンベロープ（AD）制御
各チャンネルに「Attack（立ち上がり）」「Decay（余韻）」のスライダーを搭載。
曲を再生しながらスライダーを動かし、リアルタイムに音の表情を変えることができます。迷った時も「Def」ボタン一発で、各楽器（ピアノ、ストリングス等）の自然な「黄金のデフォルト値」に復帰します。

### ⚡ 5. 極限まで軽量化したシリアル通信ステートマシン
マイコン側のシリアル受信は、Arduino標準のバッファリングや文字列変換を一切排除。
USARTのレジスタ直叩き＋1文字ごとのステートマシン解析（ポーリング方式）を採用することで、和音が密集したMIDIデータでも処理落ちやUIフリーズを発生させない、超低遅延・高安定なベースラインを確立しています。

## 🚀 使い方 (How to Use)

1. **マイコンの準備**: 本リポジトリの `UIAPduino_SN76489_MIDI.ino` をコンパイルし、マイコンに書き込みます。
2. **UIの起動**: `SN76489_MIDI.HTML` をChromeなどのWeb Serial API対応ブラウザで開きます。
3. **接続**: 画面左上の「接続」ボタンを押し、対象のシリアルポート（115200bps）を選択します。
4. **遊ぶ！**:
   - グリッドをクリックして音符を配置
   - 「MIDI」ボタンからお手持ちの `.mid` ファイルをインポート
   - スライダーを動かして自分好みの音色（エンベロープ）を探索！

---

## 🛠 ハードウェア構成 (Hardware)
- **MCU**: CH32V系 / STM32系 など（※コード内のレジスタ設定はご自身の環境に合わせて適宜調整してください）
- **Sound Chip**: SN76489 (Texas Instruments)
- **Clock**: マイコンのTimer出力（4MHz）を利用し、外部オシレータなしでSN76489を駆動。
