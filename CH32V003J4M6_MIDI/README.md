# UIAPduino: 8-Pin Microcontroller 6-Voice Synth & Web Piano Roll

![UIAPduino Piano Roll](https://img.shields.io/badge/UI-HTML5%20%7C%20Web%20Serial%20API-blue) ![Microcontroller](https://img.shields.io/badge/MCU-CH32V003J4M6-green) ![Polyphony](https://img.shields.io/badge/Polyphony-6%20Voices-orange)

わずか8ピンの超小型・低価格マイコン**「CH32V003J4M6」**の限界を突破し、最大6和音を同時発音するハードウェア・ソフトウェアシンセサイザーと、ブラウザ完結型の高機能ピアノロール・エディターの統合プロジェクトです。

専用のソフトウェアなどをインストールすることなく、PCのブラウザからUSBシリアル通信経由でマイコンを直接制御し、リッチな音楽制作体験を提供します。

## 🌟 Features (主な機能)

### 💻 Web Piano Roll Editor (`MIDI_S_040.html`)
* **完全ブラウザ完結:** Web Serial APIを使用し、ChromeやEdgeなどのブラウザだけで動作。追加ソフトは一切不要。
* **スマートMIDIインポート:** 標準MIDIファイル（.mid）を読み込み、最大6チャンネルに自動で最適化・割り当て。
* **高度な視覚化（スマートレーン機能）:** 同一音程でのノートの重なり（ショートディレイやユニゾン）を検知し、ストライプや階段状のブロックとして直感的に可視化。
* **ロングトーン編集:** ブロック上部のハンドルをドラッグ＆ドロップすることで、音符の長さ（サステイン）を直感的に調整可能。
* **プロジェクト保存/読込:** エディットした譜面データや楽器設定をJSON形式でローカルに保存・復元可能。

### 🎛️ Microcontroller Synth Engine (`CH32V003J4M6_MIDI`)
* **6ボイス・ポリフォニック:** 極小の8ピンマイコン内部で高速演算を行い、最大6音の同時発音を実現（モノラル出力）。
* **9種類のインストゥルメント・プリセット:** ピアノ、ストリングス、ベース、ベルなど、異なるエンベロープ（音量カーブ）と波形を組み合わせた音色を内蔵。
* **リアルタイム制御:** UIから送信されるシリアルコマンド（ノートオン/オフ、楽器変更など）を遅延なく処理し、スピーカーを駆動。

## 🛠 Hardware & System Requirements

* **MCU:** CH32V003J4M6 (8-pin RISC-V Microcontroller)
* **Audio Output:** PWM出力によるモノラル音声（圧電ブザーまたはアンプモジュールへ接続）
* **PC Connection:** USB-to-TTL（シリアル）変換モジュール
* **Browser:** Web Serial APIをサポートする最新のブラウザ（Google Chrome, Microsoft Edge など）

## 🚀 How to Use (使い方)

1. **マイコンの準備:** `CH32V003J4M6_MIDI` フォルダ内のスケッチを、Arduino IDE環境を使用してマイコンに書き込みます。
2. **ハードウェアの接続:** PCとマイコンをUSBシリアル変換モジュールで接続し、指定のピンにスピーカーを繋ぎます。
3. **UIの起動:** PC上で `MIDI_S_040.html` をブラウザ（Chrome推奨）で開きます。
4. **接続:** 画面左上の**「接続」**ボタンをクリックし、リストからマイコンが繋がっているシリアルポート（COMポート等）を選択します。
5. **音を鳴らす:**
   * **MIDI読込:** 既存の `.mid` ファイルを読み込ませると自動で解析されます。
   * **手動入力:** 画面下部の鍵盤、またはグリッドをクリックして音符を配置します。
6. **Play!!:** 「Play」ボタンを押して、極小チップが奏でる6和音のサウンドをお楽しみください！

## 💡 Tips & Tricks

* **ストリングス系音色について:** ストリングスやパッド系の楽器（Instrument Preset 5, 6等）はエンベロープの立ち上がりが遅く設定されています。短い音符を連続して配置すると音量が上がりきらず無音のように聞こえる場合があります。長いノート（ロングトーン）として配置するか、ピアノ系（Preset 0等）に手動で変更してください。
* **Pan (P) について:** 現行のマイコン・ファームウェアは処理能力の最適化のためモノラル出力となっています。UI上のPan設定はMIDIデータのオリジナル情報を視覚的に保持するためのものであり、実際の音声出力には影響しません。
