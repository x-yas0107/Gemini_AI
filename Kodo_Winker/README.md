# 魂動ウインカー (Kodo Winker) for CH32V003 SOP8

たった数十円の超激安RISC-Vマイコン「CH32V003 (SOP8 8ピン版)」を使用して、愛車のLEDウインカーをマツダの「魂動（こどう）ウインカー」のような生命感あふれる滑らかな点滅にアップグレードするプロジェクトです。

単純なON/OFFの点滅ではなく、**「ジワッと光り始め、余韻を残しながらスゥーッと消える」**という人間の心臓の鼓動のようなアナログチックなカーブ（ガンマ補正）を完全に再現しています。

## ✨ 主な特徴

1. **究極のアナログ発光カーブ（ガンマ補正）**
   LED特有の「機械的で直線的な明るさの変化」を排除。独自計算の二次曲線（2乗カーブ）を用いることで、白熱電球のような生々しい余韻を再現しています。
2. **PC不要！3つのボタンで完全フルカスタマイズ**
   車体に組み込んだ後でも、「点滅の周期（速さ）」と「傾き（光り方・消え方の割合）」をそれぞれ10段階で調整可能です。
3. **フラッシュメモリへの設定自動セーブ**
   EEPROMを持たないCH32V003ですが、フラッシュメモリの空き領域へ直接設定を書き込むロジックを実装。電源を切ってもお好みの設定が完全に復元されます。
4. **SOP8パッケージの「悪魔の罠」を完全攻略**
   8ピンゆえに内部で複数のピンがショート（同居）しているSOP8特有のハードウェア仕様を、レジスタの直接制御によってねじ伏せています。開発者向けのノウハウとしても非常に有用です。

## 🔌 配線図 (I/O マップ)

CH32V003J4M6 (SOP8パッケージ) のピン配置です。

| ピン番号 | 役割 | 接続先・詳細 |
| :--- | :--- | :--- |
| **Pin 1** | ウインカースイッチ入力 | ウインカーレバー等のスイッチへ (GNDに落ちるとON / 内部プルアップ) |
| **Pin 2** | VSS (GND) | 電源のマイナス（GND） |
| **Pin 3** | 選択スイッチ (PA2) | タクトスイッチ等へ (GNDに落ちるとON / 短押しでモード切替、長押しで保存) |
| **Pin 4** | VDD (電源) | +3.3V または +5.0V |
| **Pin 5** | ＋（プラス）スイッチ | タクトスイッチ等へ (GNDに落ちるとON / 設定値を上げる) |
| **Pin 6** | －（マイナス）スイッチ | タクトスイッチ等へ (GNDに落ちるとON / 設定値を下げる) |
| **Pin 7** | PWM出力 (PC4) | **LED駆動用 MOSFETのゲートへ** (HIGHで点灯) |
| **Pin 8** | SWIO | プログラム書き込み・デバッグ用 (WCH-LinkE等へ接続) |

> ⚠️ **注意:** マイコンのPin 7から直接ウインカーのLED（大電流）を光らせることはできません。必ずNチャネルMOSFETなどのスイッチング素子を間に入れて、LEDの電源を制御してください。

## 🎮 操作マニュアル（設定のしかた）

このウインカーは「周期（1回の点滅にかかる時間）」と「傾き（光り始めのジワッと感）」を、3つのボタンを使って自分好みに調整できます。

### 1. モードの切り替え（短押し）
**「選択スイッチ (Pin 3)」**を「ポンッ」と短く押すたびに、調整するモードが切り替わります。
マイコンが現在のモードを「LEDの点滅回数」で教えてくれます。

* **1回点滅した時:** 「周期（速さ）」の調整モードです。
* **2回点滅した時:** 「傾き（余韻）」の調整モードです。

### 2. 設定の変更
モードを選んだら、**「＋スイッチ」** または **「－スイッチ」** を押して数値を変更します。（それぞれ0〜9の10段階）
ボタンを押すたびに、LEDが「一瞬だけ消灯（150ms）」して、設定が変更されたことを合図します。

### 3. 設定の保存（長押し）★重要
設定が決まったら、**「選択スイッチ (Pin 3)」を【3秒間長押し】**してください。
LEDが**【3回点滅】**すれば、マイコンのフラッシュメモリへの保存が完了です！
これで、車のエンジン（電源）を切っても、次回から同じお気に入り設定で光ります。

## 🛠 開発者向けノート (SOP8の罠について)

ソースコード（`main.c`）をご覧いただくと、ボタン入力の判定に `digitalRead()` ではなく、ポートのレジスタ (`INDR`) を直接監視する複雑な論理和(`||`)の記述があることに気づくと思います。

これはCH32V003の「SOP8パッケージ」特有の仕様によるものです。8ピンに機能を詰め込むため、例えば Pin 1 には `PD6/PC3/PA1` が、Pin 5 には `PD5/PD3/PC6/PC1` が物理的に内部で繋がって（同居して）います。
そのため、通常のGPIO設定や読み込みでは互いに干渉し、ボタン入力が全く反応しない、または誤動作するという深刻な問題が発生します。

本コードでは以下の対策を施し、SOP8環境下での極めて安定したボタン操作とチャタリング防止を実現しています。
* `AFIO->PCFR1` の `PA12_RM` ビット解除によるPA1/PA2のGPIO化
* アナログ入力設定をダミーとして活用したピン干渉の無効化
* 同居する全レジスタビットの論理和による確実な入力検知
* `sel_pressed_valid` フラグによる「人間の素早い短押し」と「長押し」の完璧な分離

同様のSOP8マイコンでI/O制御に悩んでいる方の参考になれば幸いです。
