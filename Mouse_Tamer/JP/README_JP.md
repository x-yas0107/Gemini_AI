# MouseTamer-RP2040 (Ver 0.90)

## 概要
MouseTamer-RP2040は、Raspberry Pi Pico (RP2040) アーキテクチャをベースに構築された、強力なスタンドアロン型デュアルコアUSBホスト兼プロトコルアナライザーです。
`PIO-USB`ライブラリを活用し、標準的なUSBマウス（3ボタンおよび5ボタン）からの入力を読み取るUSBホストとして機能し、その移動量とクリック状態をハードウェアUARTおよびI2C経由で出力します。

単なる入力変換器にとどまらず、ハードウェア/ソフトウェアハイブリッドのシリアルモニタ（視覚的な波形再現付き）、リアルタイムI2Cスニッファー、そして入力遅延や精度をテストするための本格的な「もぐらたたき（Whack-A-Mole）」ゲームなど、強力なオンボードデバッグツールを多数搭載しています。すべての設定は内蔵のOLED UIから管理可能で、EEPROMに直接保存されます。

## 主な特徴
*   **真のデュアルコア処理**: Core 1はPIO-USBのビットバンギングとBTLオーディオ生成専用として独立稼働し、入力の取りこぼしを完全に防ぎます。Core 0はUI、画面描画、UART/I2C通信を専任します。
*   **ユニバーサルマウス対応**: 標準的な3ボタンマウスに加え、高度な5ボタンUSBマウスの認識にも対応。
*   **柔軟なデータ出力**: マウスのX/Y移動量（デルタ）とボタン状態を、UART（1200〜921600のボーレート、パリティ、ストップビット設定可能）およびI2C（最大1MHzのマスター/スレーブモード）経由で送信します。
*   **スタンドアロンOLEDインターフェース**: PCは不要です。ロータリーエンコーダーとタクトスイッチで操作できる完全なメニューシステムを搭載。
*   **オンボード・ロジックアナライザー**:
    *   **ハイブリッド・シリアルモニタ**: ハードウェアRXをキャプチャし、スタート/データ/ストップ/ギャップの信号波形を正確なピクセルタイムライン上で再現。自動HEXデコード機能付き。
    *   **I2Cスニッファー**: SCL/SDAラインの状態を記録（最大4000サンプル）し、スタート、ストップ、ACK/NAK、HEXデータをデコード。通信速度（kHz）とパケット数の自動カウント機能付き。
*   **もぐらたたき精度テスト（Whack-A-Mole）**: マウス入力を使用した内蔵アーケードゲーム。スプライトアニメーション、BTLオーディオによる効果音、EEPROMによるハイスコア記録機能を搭載。

## ハードウェア I/O マップ

| ピン | 機能 | 説明 |
| :--- | :--- | :--- |
| **GP0** | SNIFF SDA | I2Cスニッファー用入力ピン (SDAライン) |
| **GP1** | SNIFF SCL | I2Cスニッファー用入力ピン (SCLライン) |
| **GP2** | OLED SDA | SSD1306 OLEDディスプレイ用 I2C1 SDA |
| **GP3** | OLED SCL | SSD1306 OLEDディスプレイ用 I2C1 SCL |
| **GP4** | UART TX | Serial2 TX出力 (マウスデータ送信) |
| **GP5** | UART RX | Serial2 RX入力 (シリアルモニタ受信用) |
| **GP8** | I2C SDA | I2C0 SDA (マウスデータ出力用) |
| **GP9** | I2C SCL | I2C0 SCL (マウスデータ出力用) |
| **GP10** | USB D+ | PIO-USB D+ ライン (マウス接続用) |
| **GP11** | USB D- | PIO-USB D- ライン (マウス接続用) |
| **GP12** | SPK P | BTL 圧電スピーカー (+) |
| **GP13** | SPK N | BTL 圧電スピーカー (-) |
| **GP15** | SET SW | タクトスイッチ (メニュー選択/決定) |
| **GP16** | LED | WS2812 NeoPixel (ステータスインジケーター) |
| **GP26** | ENC A | ロータリーエンコーダー ピンA |
| **GP27** | ENC B | ロータリーエンコーダー ピンB |
| **GP28** | ENC SW | ロータリーエンコーダー プッシュスイッチ (メニュー選択) |
| **GP29** | ESC SW | タクトスイッチ (メニュー戻る/キャンセル) |

## 依存ライブラリと開発環境
*   **ボードパッケージ**: Earle F. Philhower `arduino-pico` (Raspberry Pi Pico/RP2040)
*   **USBスタック**: Adafruit TinyUSB Library (PIO-USB Hostとして設定)
*   **使用ライブラリ**:
    *   `Adafruit_GFX` & `Adafruit_SSD1306` (OLEDディスプレイ表示)
    *   `Adafruit_NeoPixel` (ステータスLED制御)
    *   `EEPROM` (設定保存)

## メニュー構成
1.  **Run**: データ送信の開始/停止、Auto-Startの切り替え、Visual Mode（マウスカーソルデモ）の起動。
2.  **Mouse Setting**: 3ボタンまたは5ボタンマウスのデータ解析モード選択。
3.  **Serial Setting**: ボーレート、パリティ、ストップビットの設定。
4.  **I2C Setting**: モード（マスター/スレーブ）、通信速度（100k/400k/1M）、デバイスアドレスの設定。
5.  **Application**:
    *   **Serial Monitor**: 受信したUARTデータのキャプチャ、またはデモループバックの実行。波形とHEX/ASCII値を連続スクロールで表示。
    *   **I2C Sniffer**: 外部のI2C通信をキャプチャし、デコードして波形表示。
    *   **Whack-A-Mole**: マウスの遅延と精度をテストするもぐらたたきゲーム。
6.  **Save Settings**: 現在の設定をEEPROMに保存。
