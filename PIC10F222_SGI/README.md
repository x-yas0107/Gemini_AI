# PIC10F222_SGI (Signal Injector)

## 概要 (Overview)
PIC10F222を利用した、メロディー出力型のシグナルインジェクタ（テスト信号発生器）です。
単調なピー音（発振音）ではなくメロディー（かえるのうた）を出力することで、ノイズの多い回路内でもテスト信号を耳で容易にトレース・識別できます。
矩形波出力のため高調波を豊富に含んでおり、オーディオ回路からラジオの信号経路まで幅広くトラブルシューティングに活用できます。

## 特徴 (Features)
* **極小構成:** 6ピン/8ピンのマイコン PIC10F222 を使用
* **メロディー出力:** テスト信号として「かえるのうた」を無限ループで自動再生
* **高調波成分:** 矩形波出力により、広帯域のシグナルインジェクションが可能
* **アセンブラ開発:** 限られたプログラムメモリ（256ワード）に最適化された軽量コード

## ピンアサイン (Pin Assignments)

PIC10F222 (DIP-8 / SOT-23-6)
※DIP-8パッケージを想定したピン配置です。

| Pin | Name | I/O | Connection |
|:---:|:---|:---:|:---|
| 1 | NC | - | (未接続) |
| 2 | VDD | Pwr | 電源 (+3.0V ～ +5.0V) |
| 3 | GP2 | I/O | (未使用) |
| 4 | GP1 | I/O | (未使用) |
| 5 | GP0 | Out | **シグナル出力** (プローブ側へ) |
| 6 | NC | - | (未接続) |
| 7 | VSS | Pwr | GND (グラウンド) |
| 8 | GP3 / MCLR | In | (内部MCLR無効化済み) |

## 推奨ハードウェア構成 (Hardware Setup)

マイコン自身の過電流保護と、検査対象回路の保護（DCブロック）のため、出力ピンには以下の部品を直列に接続してプローブ化してください。

`[GP0 (Pin 5)] ---> [抵抗 (1kΩ〜10kΩ)] ---> [コンデンサー (0.01µF〜0.1µF)] ---> [プローブ先端]`

* **抵抗:** 信号レベルを適正に落とし、マイコンを過電流から保護します。
* **コンデンサー:** 直流電圧をカットし、交流（メロディー信号）のみを対象回路へ送ります。耐圧はテスト対象に合わせて余裕のあるもの（50Vなど）を使用してください。

## 使い方 (Usage)
1. **電源投入:** 本機に電源を入れると、即座にメロディーのループ再生（信号出力）が開始されます。
2. **GND接続:** 本機のGND（VSS）から伸ばしたワニ口クリップ等を、テスト対象回路のGNDに接続します。
    * *※Tip: アンプの入力段など高感度な回路を探る場合は、GNDを接続せず人体アースのみの簡易テスト（プローブ接触のみ）でも信号を注入できます。信号が弱い場合はGNDを接続してください。*
3. **シグナルトレース:** プローブの先端を、対象回路の信号経路（入力から出力に向かって、あるいはその逆）に順番に当てていきます。
4. **判定:** 対象回路のスピーカーやオシロスコープからメロディーが確認できれば、プローブを当てた箇所から出力までの回路は正常に動作していると判断できます。
