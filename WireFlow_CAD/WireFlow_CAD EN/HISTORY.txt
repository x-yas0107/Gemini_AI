Change History:
- v0.01: Initial baseline created. Implemented basic screen layout, 2.54mm grid, 2-layer support, wiring functionality, component placement (resistors, capacitors, DIP-ICs), snap, zoom, and rotation features.
- v0.02: Created a component library based on KiCad standard dimensions (metric/mm).
- v0.03: Fixed canvas size to A4 landscape (297x210mm). Added automatic drawing for the drawing frame and the title block in the bottom-right corner.
- v0.04: Added zoom in/out (+/-) buttons. Implemented Undo and Redo buttons.
- v0.05: Changed the reference coordinate (0,0) for all components to Pin 1. Standardized the initial orientation of DIP-ICs to horizontal.
- v0.06: Implemented an automatic design demo for a 555 timer LED blinking circuit (resetting the workspace to blank in this version).
- v0.07: Added an "Eraser" tool; implemented functionality to delete individual components or traces upon clicking.
- v0.08: Removed the toolbar and consolidated operations into a right-click context menu. Added a status display to the top-left of the screen.
- v0.09: Implemented continuous wiring (polyline) functionality: start/continue wiring by clicking, and complete the trace by right-clicking or pressing the Esc key.
- v0.10: Added corner shape options (right-angle, 45-degree chamfer, rounded) and size specification based on the 2.54mm grid to wiring mode.
- v0.10.1: [BugFix] Fixed issues where rounded corners were rendering as straight lines and chamfers were not applying correctly during vertical movement. - v0.11: Added a feature to toggle the bend direction (vertical-priority vs. horizontal-priority) of L-shaped traces in real-time by holding the Shift key while routing.
- v0.12: Added "Free Curve" to corner shapes. Implemented smooth, continuous curve rendering using Catmull-Rom splines based on specified control points.
- v0.13: Added a function to switch to a finer grid (1.27mm) and implemented a feature to completely disable snapping (free-coordinate mode) while holding the Alt key.
- v0.14: [BugFix] Changed the Free Curve algorithm to a Centripetal Catmull-Rom spline, eliminating loops and collapsing artifacts during sharp turns.
- v0.15: [BugFix] Improved the Free Curve algorithm. Added virtual coordinate calculation for endpoints and an overshoot limiter, completely eliminating erratic line behavior and loops during sharp turns.
- v0.16: Added the "Parallel Trace" tool. Implemented functionality to select an existing trace and duplicate it via parallel translation. Also improved hit detection for line segment selection.
- v0.17: [Feature] Radically improved the Parallel Trace (offset) function. Implemented true offset calculation using normal vectors instead of simple parallel translation, and added a feature for automatic, smooth connection (S-curve routing) to specified start and end points (such as pads).
- v0.18: [BugFix] Fixed an issue where parallel trace spacing was inconsistent. Changed the offset distance to the perpendicular distance along the normal vector. Implemented dense sampling of the curve used for rendering and offset each point by a fixed distance along its tangent/normal. Start and end pads are now treated as independent connection points rather than being mixed into the parallel section's control points. Converted output to polylines to prevent spacing distortion during subsequent offset operations.
- v0.19: [BugFix] Updated Parallel Trace to perform true offsetting on a per-segment basis. Outer corners use arc joins with a radius equal to the spacing; inner corners use line segment intersections (with miter limits). Self-intersecting loops are removed. Start and end connections are separated from the parallel sections as `startCap`/`endCap` to prevent connection lines from merging with the reference path during re-offsetting.
- v0.20: [BugFix] Changed parallel tracing logic from "global offset → trim result" to fix the issue where the right end would straighten out. Vertices on the inner side with a curvature radius ≤ spacing are skipped, and the peak is cut at the intersection of the offset lines on both sides. Pad connections consist only of short caps extending from the trimmed ends.
- v0.21: [BugFix] Attempted arc-recognition-based offsetting, but discarded it because it picked up minute spline irregularities, causing failures on the inner side.
- v0.22: [BugFix] Reverted to the equidistant offset method from v0.20; added arc-length resampling and smoothing (moving average) prior to offsetting to suppress the amplification of hand tremors. Inner corners with insufficient radius are cut at the intersection.
- v0.23: [BugFix] Fixed the issue where the right end would straighten out. Preserved the curve's tail during end-point trimming and changed the pad connection to a quadratic curve aligned with the terminal tangent. Retained parallel tracing as an auxiliary function.
- v0.24: [BugFix] Fixed the issue where the end of the parallel trace would deviate significantly from the grid. Aligned start and end points based on arc-length ratios along the original line, and snapped the body ends to the grid.
- v0.25: [Feature] Standard routing uses free straight lines (including diagonals) between clicks. Corner processing (right-angle, 45-degree, or rounded) is applied only while the Space key is held down. The Space key function for component rotation applies only during placement or movement.
- v0.26: [Feature] Added Save and Load functions to the right-click menu. Implemented local file I/O using the JSON format. - v0.27: [Feature] Added a "Load Custom Part" function to import user-defined custom parts (such as SOP conversion boards) from external JSON files. Improved the system so that custom part data is automatically embedded within and restored from the board's save file (JSON).
- v0.28: [Feature] Added support for drawing rectangular pads (SMD) and internal traces for custom parts. Added presets to the standard library for SOP8/SSOP8-to-DIP8 conversion boards (including inter-pin routing).
- v0.29: [Feature] Added support for directly importing KiCad footprints (.kicad_mod). Implemented an S-expression parser to automatically interpret SMD/through-hole pad shapes, sizes, and angles, as well as silkscreen outlines, for import as CAD parts.
- v0.30: [Feature] Added a function (Library Save/Load) to save custom parts (including imported KiCad parts) as separate library files and load them in bulk. Reorganized the right-click menu.
- v0.31: [Feature] Added "1-pin land" and "via" to standard parts. Implemented a function to automatically place a via and switch layers by pressing the "V" key while routing. Moved Undo/Redo to the top of the menu.
- v0.32: [Feature] Inverted routing colors: changed the bottom layer (solder side) to red and the top layer (component side) to blue. Added menu options to toggle the visibility (ON/OFF) of traces and silkscreen for each layer.
- v0.33: [Feature] Added a silkscreen text placement function. Supports input, placement, movement, rotation, deletion, and saving/loading of arbitrary text. Linked to the silkscreen visibility toggle.
- v0.34: [Feature] Enhanced text functionality. Added a font size toggle (Small, Medium, Large). Implemented a function to re-edit placed text by double-clicking it. Added a precise hit-detection algorithm specifically for text that accounts for character length and angle, improving the usability of move and delete operations.
- v0.35: [Feature] Finalized the CAD name as "WireFlow_CAD." Revamped the drawing frame (title block) design into a professional table layout. Enabled individual editing of frame fields (TITLE, DESIGNER, DATE, REV) via double-click and added functionality to save settings as JSON.
- v0.36: [Feature] Modified the layout of the bottom section of the drawing frame. Positioned the CAD name (WireFlow CAD) and subtitle (Intuitive Circuit Design) on the left, the date in the center, and the revision on the right.
- v0.37: [BugFix] Fixed an issue where the thick outer border (margin frame) of the A4 sheet had disappeared; restored it as a solid, thick line (3px).
- v0.38: [Feature] Added an "Idle (Select)" mode. Set Idle mode as the default state and enhanced the "cancel" and "return to idle" functions triggered by the Esc key. Added "Select / Idle" to the right-click menu.
- v0.39: [Feature] Compacted the right-click menu UI (reduced font size; halved padding and margins). Organized the component placement menu into a sub-hierarchical structure: "Basic Parts," "ICs & Adapter Boards," and "Custom Parts."
- v0.40: [Feature] Implemented a custom modal window system. Replaced standard `alert`/`prompt` dialogs with a unified, custom UI displayed in the center of the screen (featuring a dimmed background).
- v0.41: [Feature] Converted "Resistor" and "Capacitor" placement options into sub-menus and added footprint variations based on size (e.g., axial, SMD). Implemented a class (`.scrollable-menu`) with a maximum height (220px) and an automatic scrollbar to prevent the menu from extending off-screen.
- v0.42: [Feature] Implemented a print output function. Added support for actual-size (A4) printing, partial printing (visible area), and layer-specific output. Implemented automatic inversion to a white background with black silkscreen specifically for printing. Added a mirrored printing (horizontal flip) option. Expanded the component library to include LEDs (3mm/5mm), coils (axial/radial), and connectors (pin headers, 2–8 pins).
- v0.43: [Feature] Added a "Mirrored Printing (Horizontal Flip)" function to the print dialog. Implemented logic to flip the Canvas output during image generation.
- v0.44: [Feature] Added color mode selection for printing (Color / Monochrome Solid Black / Negative Inversion/White-out). Fully supports pure black/white-out output for mask creation.
- v0.45: [Feature] Expanded the grid system to support both inch-based (2.54/1.27/0.635mm) and metric-based (1.0/0.5mm) grids. Implemented shape drawing tools (rectangle/circle; outline/fill) for creating custom pads and solid ground planes.
- v0.46: [Feature] Revamped zooming (magnification/reduction) to use true vector zooming. Implemented zoom-to-cursor functionality and added a "smart grid" display that automatically thins out grid lines (e.g., 0.5mm grid) when zoomed out.
- v0.47: [BugFix] Fixed a bug where inch-based (2.54mm) major grid lines were drawn alongside metric-based (1.0mm/0.5mm) grids. Changed the specification to draw independent major grid lines for metric and inch systems.
- v0.48: [Feature] Implemented screen panning via middle-button (wheel) dragging and a "Fit to Screen" function via middle-button double-clicking. - v0.49: [Feature] Revamped the "Fit All" algorithm (triggered by double-clicking the middle mouse button) to automatically fit the actual drawing area (bounding box) rather than the entire paper size.
- v0.50: [BugFix] Extended the detection time for the middle-mouse double-click to 600ms. Adjusted margin calculations for the "Fit All" (auto-fit) function to maximize the display area on the screen.
- v0.51: [Feature] Drastically improved the KiCad import function. Added support for parsing slotted holes, rounded-corner pads, arcs, and text. Added a preview window (viewport).
- v0.52: [Feature] Added a "Layer Mapping" function to the import preview screen.
- v0.53: [BugFix] Improved the pad rendering engine to ensure pads retain their original gold color during layer mapping.
- v0.54: [Feature] Added support for fully parsing and rendering KiCad polygon fills (`fp_poly`).
