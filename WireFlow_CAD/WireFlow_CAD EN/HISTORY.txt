# WireFlow CAD — Change History

## v0.87
- Submenu arrows (▶ / ◀) no longer overlap item labels.

## v0.86
- Once a submenu opens to the left, nested menus keep opening left.


## v0.85
- Mirror selected silk text and footprint text horizontally (Edit menu / Ctrl+M).
- Right-click submenus open to the left or up when they would leave the window.

## v0.84
- Full English UI: filename, menus, dialogs, status, part names, and prompts.

## v0.83
- Paste remaps traces and shapes onto the current drawing layer (front ↔ back, silk ↔ outline).

## v0.82
- Box select (drag), single select (click), copy/paste (Ctrl+C/V), bulk move, and Delete.
- Traces can be selected and moved.

## v0.81
- Refactored part drawing (`drawSinglePart` and related helpers). Removed unused math. About 400 lines smaller.

## v0.80
- Coordinate origin (0,0) and grid snap origin moved from the paper edge to the top-left of the drawing frame.
- Default designer for new drawings: `@yas0107`.
- Title-block WireFlow CAD logo enlarged.

## v0.79
- F3 toggles the top-left help overlay.
- ABS/REL coordinates moved from the overlay to the top menu bar (right side).
- REL appears only while drawing, on a second status row.

## v0.78
- Thin top menu bar with F1/F2 pulldowns.
- Right-click menu grouped into Draw / Edit / View.
- Manual CFG file export removed.

## v0.77
- Autosave/restore of settings in localStorage (grid, trace width, corners, layer visibility).

## v0.76
- Silk (white) and outline (yellow) became drawable layers, in addition to two copper layers.

## v0.75
- Metric grid: 10 mm and 5 mm.

## v0.74
- Circles are center + radius.
- REL shows R (radius) and D (diameter) for circles, W/H for rectangles.

## v0.73
- Coordinate readout. ABS from the sheet origin; REL from the start of the current line/circle/rect, in mm.

## v0.72
- Chamfer/fillet sizes 1G–5G.
- Actual radius = grid × G × 0.5 (on a 2.54 mm grid, 1G = R 1.27 mm).

## v0.70
- Print scale X/Y labels no longer overlap at the origin.

## v0.69
- Vertical 100 mm print scale added.

## v0.68
- Print: 100 mm scale bar and measured X/Y correction.

## v0.67
- Reverted display to the v0.64 model. Zoom cap 4× (full-sheet canvas at high zoom went white).

## v0.64
- 0.1 mm grid visibility (zoom cap and display threshold).
- Offset inner-R rebuild that ballooned corners was withdrawn; standard offset restored.

## v0.63
- Metric grid 0.25 mm / 0.1 mm. Fine ticks only when zoomed in; 1 mm is the major pitch.

## v0.62
- Offset inner corners no longer collapse to a point. Remaining radius or a minimum-R arc is kept.

## v0.61
- After a KiCad import commit, the settings window no longer waits for Cancel. It closes first, then shows the done message.

## v0.60
- KiCad custom pad primitives, `fp_rect`, `fp_curve`, and stroke width.
- Logos / copper artwork no longer import as outlines only.

## v0.59
- Circles and arcs stay as circles/arcs (not polylines).
- Supports both old form (start = center + angle) and new form (start/mid/end).

## v0.58
- Eraser can delete a single text item inside a footprint. The part body remains.

## v0.57
- Outline display layer added (front / back / silk / outline).
- KiCad Fab separated from silk. Print can toggle outline independently.

## v0.56
- KiCad layer mapping lists all standard layers with checkboxes.
- “Found” marks and selection state are separate.

## v0.55
- KiCad mapping UI became target-driven: pick which KiCad layer fills each WireFlow layer (front / back / silk).

## v0.54
- Full parse and draw of KiCad filled polygons (`fp_poly`).

## v0.53
- Pad drawing keeps gold pad color after layer mapping.

## v0.52
- Layer mapping on the import preview.

## v0.51
- KiCad import rewritten: oblong / rounded pads, arcs, text. Preview viewport added.

## v0.50
- Middle-button double-click window extended to 600 ms. Fit-to-drawing padding improved.

## v0.49
- Fit-to-screen uses the drawing bounding box, not the full sheet.

## v0.48
- Middle-button drag pan. Middle double-click fit-to-screen.

## v0.47
- Metric grids no longer draw leftover inch majors. Inch and metric majors are independent.

## v0.46
- True vector zoom, cursor-centered zoom, smart grid thinning when zoomed out.

## v0.45
- Inch grids (2.54 / 1.27 / 0.635 mm) and metric (1.0 / 0.5 mm).
- Shape tool: rectangle / circle, stroke or fill (for custom pads and pours).

## v0.44
- Print color modes: color / mono solid black / negative (mask making).

## v0.43
- Mirror print (horizontal flip) via canvas transform.

## v0.42
- Print: actual-size A4 or current view, layer filters, white paper / black silk while printing.
- Library: LED 3/5 mm, axial/radial inductors, pin headers 2–8.

## v0.41
- Resistor / capacitor size submenus (axial, SMD). Scrollable menus (max 220 px).

## v0.40
- Custom modal instead of `alert` / `prompt`.

## v0.39
- Compact right-click menu. Parts grouped: basic / IC-adapters / custom.

## v0.38
- Idle/select mode as default. Esc cancels and returns to idle.

## v0.37
- Restored the heavy A4 margin frame (3 px).

## v0.36
- Title-block bottom row: CAD name + tagline, date, revision.

## v0.35
- Product name: WireFlow CAD. Formal title block. TITLE / DESIGNER / DATE / REV editable by double-click and saved in JSON.

## v0.34
- Text sizes S/M/L. Double-click to edit placed text. Text hit-testing uses length and angle.

## v0.33
- Silk text: place, move, rotate, erase, save/load. Follows silk visibility.

## v0.32
- Colors: back/solder = red, front/component = blue. Per-layer visibility on/off.

## v0.31
- Standard parts: single pad and via. V while routing places a via and flips copper layer.

## v0.30
- Custom parts (including KiCad imports) as a separate library file. Menu cleanup.

## v0.29
- Direct KiCad `.kicad_mod` load. S-expression parser for SMD/TH pads and silk outlines.

## v0.28
- Custom rectangular SMD pads and internal copper. SOP8 / SSOP8-to-DIP8 adapters in the stock library.

## v0.27
- User custom parts from external JSON. Custom defs are also embedded in the board JSON.

## v0.26
- Save / load board as local JSON.

## v0.25
- Default routing is a free straight segment (diagonals allowed). Square / 45° / fillet only while Space is held.
- Space rotates parts only in place/move.

## v0.16–v0.24
- Offset-copy tool, then several geometry fixes (true normal offset, arc joins, self-intersection trim, resample/smoothing, end caps, grid snap of ends). Kept as a helper, not a perfect zone engine.

## v0.12–v0.15
- Free-curve corners via Catmull-Rom, then centripetal CR, then virtual endpoints + overshoot limiter.

## v0.10–v0.11
- Corner styles: square, 45° chamfer, fillet, sized in grid units. Shift flips L-bend priority.

## v0.09
- Continuous polyline routing. Click to start/continue, right-click or Esc to finish.

## v0.08
- Toolbar removed. Operations moved to the right-click menu. Status overlay added.

## v0.07
- Eraser: click a part or trace to delete it.

## v0.06
- 555 blinker demo, then reset new documents to a blank sheet.

## v0.05
- Part origin (0,0) at pin 1. DIP ICs default landscape.

## v0.04
- Zoom +/− buttons. Undo / Redo.

## v0.03
- Fixed A4 landscape (297 × 210 mm). Frame and title block.

## v0.02
- Part library on KiCad-style millimetre sizes.

## v0.01
- First baseline: 2.54 mm grid, two layers, routing, resistor/capacitor/DIP, snap, zoom, rotate.
